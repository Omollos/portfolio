# Steve Omollo — Developer Portfolio

Personal developer portfolio built with React and Vite.

The portfolio showcases my software development projects, technical skills, technical writing, education, and professional background.

## Live Website

https://steveomollo.vercel.app

## Features

* Responsive design for desktop, tablet, and mobile
* Developer profile and introduction
* About section
* Technical skills
* Project showcase
* Technical writing / Dev.to articles
* Hobbies and interests
* Downloadable resume
* Contact section
* Social media links

## Projects

### Guidely

An internal knowledge assistant that retrieves relevant information from company documents and uses AI to generate answers with supporting sources.

**Technologies:** React, FastAPI, FAISS

### Loba

A community-driven platform for collecting, documenting, and translating Kenyan local-language vocabulary, with structured storage for language data.

**Technologies:** Go, JavaScript, PostgreSQL

### Lem-in

A Go-based pathfinding project that parses an ant colony, validates the graph, and uses BFS to find efficient non-overlapping paths through the network.

**Technologies:** Go, Algorithms, BFS

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Omollos/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
